# papers

Michael Friendly's papers, preprints, talk slides and supplementary materials, served by GitHub Pages at
**<https://friendly.github.io/papers/>**.

These files were previously at `https://www.datavis.ca/papers/`. The folder layout is unchanged, so an old link
can be fixed by swapping the host:

```
https://www.datavis.ca/papers/koln/kolnpapr.pdf
https://friendly.github.io/papers/koln/kolnpapr.pdf
```

Where a paper has a published version, prefer citing its DOI.

## Notes
